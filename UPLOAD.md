# Manual GitHub upload

1. Extract the ZIP.
2. Open `ykimran/Automatic-OCP-System-using-Arduino` on GitHub.
3. Choose **Add file > Upload files**.
4. Open the extracted `Automatic-OCP-System-using-Arduino` folder and drag its contents into the upload area, including all subfolders. `README.md` should be at the repository root, not inside an extra enclosing folder.
5. Review the file list and commit the upload. Replace the placeholder README with the included README.

The package excludes Git history and credentials. Every included file is below 25 MB for browser upload.
